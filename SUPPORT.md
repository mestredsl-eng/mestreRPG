# Suporte

Este repositório mantém o código do Mestre RPG. Para agilizar a ajuda, escolha o canal conforme o tipo de necessidade.

## Instalação, atualização e operação

- Comece pelo [README](README.md).
- Para inicialização, atualização, acesso externo, backups, restauração e diagnóstico, consulte [docs/GUIA-OPERACAO.md](docs/GUIA-OPERACAO.md).
- Antes de atualizar uma instalação em uso, confirme que há um backup íntegro. Não compartilhe o banco ou os arquivos de uma campanha para pedir ajuda.

## Reportar um problema

Use o formulário **Relatar um bug** em [Issues](https://github.com/mestredsl-eng/mestreRPG/issues). Informe versão, sistema operacional, navegador quando relevante, passos para reproduzir e resultado esperado/observado.

Envie somente logs sanitizados. Nunca publique senhas, cookies, tokens, chaves, dados pessoais, conteúdo privado de campanha ou backups.

## Sugerir uma melhoria

Use o formulário **Propor uma melhoria** em [Issues](https://github.com/mestredsl-eng/mestreRPG/issues). Descreva o problema que a ideia resolve, quem seria afetado e alternativas consideradas.

## Segurança e conduta

- Para vulnerabilidades, siga [SECURITY.md](SECURITY.md). Não use uma Issue pública.
- Para problemas de convivência, consulte [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) e faça o relato em privado ao mantenedor.

## Expectativa de resposta

Issues e Pull Requests são analisadas conforme prioridade, capacidade de manutenção e compatibilidade com o projeto. Não há prazo de resposta ou suporte garantido. Um relato claro, reproduzível e sem dados sensíveis ajuda bastante.
